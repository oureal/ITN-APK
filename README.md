# TC Brunn ITN Android App

Diese App öffnet die NÖTV-ITN-Rangliste und filtert automatisch nach `TC Brunn/Geb`.

## APK online mit GitHub Actions bauen

1. Alle Dateien dieses Ordners in ein GitHub-Repository hochladen.
2. In GitHub auf **Actions** gehen.
3. Workflow **Build Android APK** auswählen.
4. **Run workflow** klicken.
5. Nach erfolgreichem Lauf unten bei **Artifacts** die Datei **TCBrunnITN-debug-apk** herunterladen.
6. ZIP entpacken, darin liegt `app-debug.apk`.
7. APK auf Android installieren.

Hinweis: Das ist eine Debug-APK. Für private Nutzung ist das ausreichend.
